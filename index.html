Как добавить товар:

1. Открой index.html
2. Найди массив products
3. Добавь объект:
{
  id: 7,
  type: "bot", // или "service"
  name: "Название",
  price: 490,
  image: "img/mybot.jpg", // путь к JPG картинке
  description: "Описание..."
}
4. Сохрани изменения.
